# calculator_v1 releases

Public distribution point for [Calculator](https://github.com/venkateshTakumi/calculator_v1) (source is private).

This repo holds:
- `version.json` — the manifest the app's built-in updater checks.
- GitHub Releases, each carrying that version's `calculator_v1_setup.exe` installer as an asset.

No application source code is published here.
